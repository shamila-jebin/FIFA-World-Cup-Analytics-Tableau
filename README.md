# ⚽ FIFA World Cup Analytics Dashboard – Tableau

## 📌 Project Overview

This project presents a FIFA World Cup Analytics Dashboard built using Tableau to explore historical FIFA World Cup match data.

The dashboard provides insights into match statistics, goal-scoring trends, match results, tournament stages, and team performance through visualizations.

## 🎯 Project Objectives

- Analyze historical FIFA World Cup match data.
- Explore total matches and total goals.
- Understand average goals per match.
- Analyze match results, including home wins, away wins, and draws.
- Explore goal trends across tournaments.
- Compare match statistics across different stages and countries.
- Develop an interactive and informative dashboard.

## 📊 Dashboard Highlights

- Total Matches
- Total Goals
- Average Goals per Match
- Goals by Tournament Year
- Match Results Analysis
- Goals by Stage
- Matches by Country
- Team Wins Analysis
